# 高级阶段负荷自回归：RPE 锚定的 e1RM 配重

## Context

确定性训练引擎的高级 DUP 阶段（18+ 月）本应区别于新手的线性渐进，但实现上仍是新手式的「达标就 +固定 kg」：

1. `plannedTrainingTypeWeightKg` 在用户完成目标次数后，给上次重量加一个固定增量（上肢 +1.25kg、下肢 +2.5kg），与新手引擎的 `incrementKg` 逻辑同构。对真正训练 18 个月以上的人，线性增重早已耗尽，需要波动式/自回归。
2. 目标 RPE（力量 9 / 肌肥大 8 / 耐力 7）**只写在动作 notes 文本里，从不参与配重计算**——RPE 是装饰性的，"DUP 自回归"成了一句空话。
3. 高级固定增量（1.25 / 2.5kg）反而**大于**中级（0.5 / 1kg），与「训练年限越长、增量越小」的常识倒挂。

来源：训练引擎科学性审计（2026-06-18），见 Issue #48。

一个根本约束:**数据模型没有记录用户主观 RPE/RIR**。`WorkoutSessionSet` 只有 `actualWeightKg` / `actualReps`，没有"这组练完感觉几分"的字段。因此"基于 RPE 反馈"的自回归无法直接落地，只能基于**块内客观表现**（实际重量 × 次数）。

## Decision

**高级阶段改用 RPE 锚定的 e1RM 自回归配重，取代固定增量线性加重。**

每个主训练动作的下次配重按以下规则计算：

```
e1RM = 重量 × (1 + 次数/30)            // Epley 估计 1RM
强度  = RPE_INTENSITY[该训练类型的 RPE]  // RPE 9→0.90 / RPE 8→0.75 / RPE 7→0.62
下次配重 = round_to_quarter(e1RM × 强度)
```

- **e1RM 取「最近一次完成表现里、最佳工作组」的值**，作为自回归的"已证容量"。表现好（更大重量 / 更多次数）→ e1RM 升 → 配重升;状态差 / 未达标 → e1RM 降 → 配重回落。负荷随表现波动，而非单调的 +kg 阶梯。
- **RPE 经强度系数真正参与配重决策**:同一表现下，力量日（RPE 9）配重高于耐力日（RPE 7）。RPE 不再是装饰文本。
- **进展按 e1RM 的比例缩放**:刚好达标约 +5%（力量），绝对步长随负荷增长而非固定 kg。这同时消除了"高级固定增量大于中级"的倒挂——高级根本不再有固定 kg 增量可比。
- e1RM 的计算跨训练类型通用（Epley 已对次数归一），无历史时回落到保守起始重量 `plannedWeightKg`。

强度系数的取值参照标准 %1RM-at-RM 表（5RM≈87%、12RM≈70-75%、20RM≈60%）并略上偏，使"刚好达标"产生温和的正向进展，再由自回归自我限幅（接近真实容量时不再达标 → e1RM 平台 → 配重平台）。

## Consequences

### 实现要点

- `lib/workout/engine/advanced-engine.ts`:
  - 新增 `estimatedOneRepMaxKg`（Epley）、`recentEstimatedOneRepMaxKg`（取最佳组 e1RM）、`RPE_INTENSITY` 映射。
  - `plannedTrainingTypeWeightKg` 改为 `round(e1RM × RPE_INTENSITY[rpe])`，无历史时回落保守起始重量。
  - 删除废弃的 `incrementKg` / `latestWeightKg` / `completedTargetReps` 及 `TrainingTypeConfig.repRange`（次数区间不再用于筛选历史）。
  - 动作提示由"完成目标次数后再加重"改为自回归措辞,使 UI 也不再暗示线性加重。
- 减载（deload）逻辑不变：仍对算出的 `plannedWeight` 应用 -30% 强度 / -33% 组数。
- `CONTEXT.md` 的「渐进规则」与「高级波动周期化」段落同步更新术语。

### 取舍

- **优点**:RPE 名副其实地驱动负荷;负荷双向自回归（升/降），更贴近高级训练者现实;增量梯度倒挂自然消除;纯确定性、可测试、可复现。
- **代价 / 已知局限**:
  - e1RM 自回归基于客观表现，而非主观费力度。若未来引入用户主观 RPE/RIR 输入字段，可升级为"目标 RPE − 实际 RPE"的偏差调节,届时本 ADR 可被取代或补充。
  - Epley 公式在高次数（如耐力 20 次）下精度下降;当前接受此近似，因其仍能正确反映表现的相对升降。
  - 取"最近一次"表现使配重对单次异常（一次状态特别差/特别好）较敏感;当前接受，符合 DUP 每个训练类型独立、对近期状态响应的设计意图。

### 测试

`tests/advanced-engine.test.ts` 以 TDD 红绿循环新增 5 个行为测试：e1RM×强度配重、向下自回归（非单调阶梯）、RPE 改变配重、进展按负荷比例缩放、自回归提示文案。

## Alternatives Considered

### 基于主观 RPE/RIR 反馈的自回归
经典自回归是用"目标 RPE 与实际 RPE 的偏差"调节负荷。
- **拒绝理由**:数据模型未捕获主观 RPE/RIR，需新增输入字段与 UI，超出本次增强范围。留作未来升级路径。

### 降级 RPE 为纯提示 + 修正增量梯度
明确承认不做真自回归:RPE 仅作提示文本，并把高级增量改为小于中级（如上 0.25 / 下 0.5）。
- **拒绝理由**:能修正倒挂，但仍是固定线性加重，不满足 #48"引入真正的波动/自回归"的首要期望。

### 表现分级波动（无 e1RM）
按实际次数相对目标区间的超额 / 不足分档调节（大幅超额→大档、刚达标→小档、未达标→维持/降）。
- **拒绝理由**:可实现波动，但 RPE 对配重的影响弱、档位为人为离散值;e1RM 方案让 RPE 直接连续地决定强度，更自然且更易解释。
