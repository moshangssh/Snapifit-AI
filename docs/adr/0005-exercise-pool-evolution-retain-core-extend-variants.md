# 动作库分阶段演进：保留核心基准 + 扩展变式池

## Context

确定性训练引擎设计了三个训练阶段（新手/中级/高级），每个阶段有不同的周期化模型和训练参数。但阶段切换时，**动作库如何演进**是一个关键架构问题：

1. 完全替换？用户丢失所有历史进度的参照系
2. 完全不变？中高级用户得不到刺激多样性
3. 保留 + 扩展？既有连续性又有新鲜感

用户有 824 个动作库，需要在三个阶段间合理分配，同时考虑 AS 安全约束。

## Decision

**采用"保留核心基准 + 扩展变式池"策略。**

动作库是**累加的，不是替换的**。每个阶段保留上一阶段的核心基准动作（用于追踪长期 PR），扩展新的变式动作（提供刺激多样性）。

### 三阶段动作池配置

| 阶段 | 动作池构成 | 总数 | 基准动作作用 |
|------|-----------|------|-------------|
| 新手（0-6月） | 核心 20 个 | 20 | 建立力量基础，反复练 |
| 中级（6-18月） | 保留 10 + 扩展 20 | 30 | 保留基准追踪 PR，变式提供多样性 |
| 高级（18+月） | 保留 5 + 全库开放 | ~50+ | 终生基准锚定进步，其他自由组合 |

### 新手阶段核心池（20 个）

**筛选规则：**
```typescript
tags: "STRENGTH"
equipments: 优先 "MACHINE" 和 "DUMBBELL"（器械为主）
mechanics: COMPOUND 和 ISOLATION 都要
排除: 杠铃深蹲、硬拉、过顶推等高风险动作
标记: NOVICE_CORE
```

**分布：**
- 胸: 3 个（器械推胸、哑铃卧推、夹胸）
- 背: 3 个（坐姿划船、高位下拉、单臂划船）
- 肩: 3 个（哑铃侧平举、器械肩推、后肩飞鸟）
- 腿: 4 个（腿举、腿弯举、臀桥、髋外展）
- 臂: 4 个（二头弯举、三头下压、锤式弯举、过顶臂屈伸）
- 核心: 3 个（平板支撑、悬垂举腿、侧平板）

**新手阶段使用方式：**
- 4 个模板里轮换这 20 个动作
- 每个动作大约 2-3 周出现一次
- 专注于"围绕少量核心动作持续渐进"

### 中级阶段演进（30 个）

**保留 10 个基准动作：**
```typescript
标记: BENCHMARK（终生基准）

用途: 追踪长期 PR（个人记录）
- 胸: 器械推胸（推力基准）
- 背: 坐姿划船（拉力基准）
- 肩: 哑铃侧平举（肩部基准）
- 腿: 腿举、臀桥（下肢基准）
- 臂: 二头弯举、三头下压
- 核心: 悬垂举腿
```

**扩展 20 个变式动作：**
```typescript
标记: INTERMEDIATE_VARIANT

筛选规则:
  - 与基准动作同肌群、不同角度/器械/握法
  - 例如：基准是"器械推胸" → 变式包括"上斜推、下斜推、单臂推"

分布:
  - 胸: +上斜推、+下斜推、+单臂推胸
  - 背: +直臂下拉、+T杠划船、+反手下拉
  - 肩: +前平举、+阿诺推、+面拉
  - 腿: +哈克深蹲、+单腿臀桥、+保加利亚蹲
  - 臂: +集中弯举、+法式推举、+窄握卧推
  - 核心: +悬垂转体、+药球转体、+抗旋转
```

**中级 6 个模板的动作分配逻辑：**
```
模板 1（测试周）: 基准动作为主
模板 2-3: 变式组 A
模板 4-5: 变式组 B
模板 6（测试周）: 基准动作为主

→ 每 6 次训练：
  - 2 次基准动作（追踪 PR：这周器械推胸能推多重？）
  - 4 次变式动作（刺激多样性：从不同角度刺激胸肌）
```

**关键逻辑：基准动作的 PR 追踪贯穿整个中级阶段（6-18 个月）。**

例如：
- 第 6 个月末：器械推胸 80kg × 10 reps
- 第 12 个月：器械推胸 95kg × 10 reps（+15kg）
- 第 18 个月：器械推胸 105kg × 10 reps（+25kg）

这条进步曲线是你 12 个月努力的直接证明。

### 高级阶段演进（50+ 个）

**保留 5 个终生基准：**
```typescript
标记: LIFETIME_BENCHMARK

用途: 终生力量锚点（用于"我比 2 年前强多少"）
- 器械推胸（推力）
- 坐姿划船（拉力）
- 腿举（下肢）
- 哑铃侧平举（肩部）
- 悬垂举腿（核心）
```

**全库开放：**
```typescript
条件扩展:
  - 如果 AS 改善（用户标记"这些动作现在可以做了"）:
    + 杠铃卧推、杠铃划船、前蹲、肩推

  - 如果仍需避开高风险:
    继续用器械和哑铃，但开放全库变式（~45 个）

高级动作特征:
  - 包含单侧训练（单臂、单腿，更高平衡要求）
  - 包含复杂复合动作（例如哑铃推举 + 侧平举组合）
  - 包含爆发力动作（如果用户感兴趣）
```

**高级 6 个模板的动作分配逻辑：**
```
力量日: 基准动作（测 1-3RM）
肌肥大日: 变式 A（8-12 reps）
耐力日: 变式 B（15-20 reps）

→ 基准动作一周出现 2 次（力量日上 + 力量日下）
→ 其他 4 次完全不重复，动作池足够大可以持续轮换
```

## Consequences

### 实现要点

**动作库 tag 体系：**
```typescript
// 阶段标记
NOVICE_CORE        // 新手核心池（20 个）
BENCHMARK          // 中级保留基准（10 个，是 NOVICE_CORE 的子集）
LIFETIME_BENCHMARK // 高级终生基准（5 个，是 BENCHMARK 的子集）
INTERMEDIATE_VARIANT // 中级变式（20 个）
ADVANCED_VARIANT     // 高级变式（~25 个）

// 关系
LIFETIME_BENCHMARK ⊂ BENCHMARK ⊂ NOVICE_CORE
```

**阶段切换时的动作池更新：**
```typescript
// 新手 → 中级
function transitionToIntermediate(history: SessionHistory) {
  // 从新手核心 20 个中，选出 10 个作为基准
  const benchmarks = selectBenchmarks(history, {
    criteria: "highest_volume_and_progress",  // 选练得最多、进步最大的
    count: 10
  })

  // 这 10 个动作打上 BENCHMARK 标记
  // 用户的历史 PR 数据继续保留，作为中级起点

  // 扩展 20 个变式
  const variants = selectVariants(benchmarks, {
    sameMuscleDifferentAngle: true
  })

  return {
    benchmarks,    // 10 个，一周 2 次
    variants       // 20 个，一周 4 次轮换
  }
}

// 中级 → 高级
function transitionToAdvanced(history: SessionHistory) {
  // 从中级基准 10 个中，选出 5 个终生基准
  const lifetimeBenchmarks = selectLifetimeBenchmarks(history, {
    criteria: "most_iconic_movements",  // 最标志性的动作
    count: 5
  })

  // 开放全库（如果 AS 改善，包含杠铃复合）
  const advancedPool = openFullCatalog({
    includeBarbell: user.canDoBarbell  // 用户标记
  })

  return {
    lifetimeBenchmarks,  // 5 个，每周 2 次（力量日）
    advancedPool         // ~45 个，其他日轮换
  }
}
```

### 用户体验

**新手阶段（第 1-6 个月）：**
- 每次训练看到的动作大多是"熟悉的"
- 引擎反复让你练同样的动作，你能感受到"上次 60kg，这次 62.5kg"的渐进
- 动作池小，降低选择焦虑

**中级阶段（第 7-18 个月）：**
- 每 3 次训练有 1 次是"基准测试"（器械推胸又能推多重了？）
- 其他 2 次是新鲜的变式（今天练上斜推，下次练单臂推）
- 你的"器械推胸 PR"从 80kg 一路追踪到 105kg，成就感累积

**高级阶段（第 19+ 个月）：**
- 每月 2 次"力量日"测试终生基准（我的器械推胸 1RM 到哪了？）
- 其他训练完全不重复，动作库足够大可以玩一年不腻
- 终生基准成为你的"力量身份证"（我能推 120kg × 5）

## Alternatives Considered

### 完全替换（策略 B）
每个阶段用全新的动作池。
- **拒绝理由**：用户丢失历史进度参照系。无法回答"我比半年前强多少"，因为动作都变了。

### 渐进替换（策略 C）
新手保留 50% → 中级保留 33% → 高级保留 12%，逐步淘汰。
- **拒绝理由**：中级保留 33%（10/30）与我们的方案一致，但高级保留 12% 太少。用户需要一些"终生基准"来锚定 2-3 年的进步。

### 完全不变（策略 D）
所有阶段用同样的 20 个动作，只改训练参数。
- **拒绝理由**：中高级用户会觉得枯燥，且失去了"刺激多样性"带来的肌肉适应突破。

## References

- 渐进超负荷原则：长期追踪同一动作的 PR 是力量进步的金标准
- 刺激多样性原则：中高级训练者需要多角度刺激来突破适应平台
- 动作熟练度资产：6 个月建立的神经适应和动作模式不应轻易丢弃
